Wildcard domain rules

From a name pattern to a reviewed address set.

Match names from the Windows DNS cache and resolve candidates with Resolve-DnsName. Review the resulting addresses before applying block rules.

An optional elevated worker can refresh enabled patterns about every five minutes. Blocking applies to resolved addresses, not encrypted names inside a session.

Local architecture

Your machine is the boundary.

The browser talks to a local FastAPI service. Windows telemetry comes from psutil and PowerShell. Administrative firewall changes cross UAC deliberately.

01 / PRESENT

Fluent console

React 18 and Fluent UI v9 in the browser, with local server-state polling.

02 / OBSERVE

Local API

FastAPI on 127.0.0.1:8765, SQLite history, psutil, and Windows queries.

03 / CHANGE

Elevated Windows

UAC-approved PowerShell for firewall mutations, audit policy, and optional capture.
