Firewall Guard
Overview Features Specifications Operations How to run it

Built for one PC.

The browser talks to a local API. Windows Firewall changes only after you approve an elevated PowerShell broker.

System
Windows 11. Windows 10 can run with reduced PowerShell behavior.
Python
3.11 or newer, for the local API.
Node.js
20 or newer, only to install or rebuild the dashboard.
Rights
Observation does not need elevation. Live rules need one UAC approval per batch.
Network
API bound to 127.0.0.1, port 8765. Dashboard dev server on port 5173.
Dashboard
React 18 and Fluent UI v9.
Action
Block only. No allow rules are created.
Direction
Outbound for the managed workflow.
Name
Prefix FGF-. Group Firewall Guard Fluent.
Batch
Up to 50 targets. One elevation. A result for each item.
Removal
Only rules this console created. Other products are left in place.
Check
Create and delete are verified with Get-NetFirewallRule.
Sessions
A new block does not always cut a connection that is already open.
Metrics
About every 3 seconds for CPU, memory, network, and disk.
GPU
About every 4 seconds. nvidia-smi when present, otherwise Windows GPU counters.
Domains
Optional elevated refresh about every 5 minutes.
Policies
policies.json is a catalog. It is not a background enforcer.
End process
Confirmation required. Critical Windows processes and this console cannot be ended.

What it will not claim.

High disk writes and a new connection are clues. They are not the contents of a transfer. Group Policy, a VPN, or another security product can still allow or block the same path.
