  • End a process with confirmation and backend guards for selected critical processes.

Managed rules

A firewall change you can account for.

Create block rules for applications, services, and remote addresses. Review targets before elevation, then inspect per-target creation results.

  • Outbound by default, with inbound available in the block dialog.
  • Up to 50 targets per batch creation request.
  • Names carry the FGF- prefix and the Firewall Guard Fluent group.

Firewall events

Events stay structured.

Inspect recent firewall and Windows Filtering Platform events with direction, application, source, destination, and the raw event message when available.

Packet-audit visibility depends on Windows audit policy and event-log access. Empty results can mean unavailable evidence, not proof that no traffic occurred.
